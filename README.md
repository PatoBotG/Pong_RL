Per accedir al codi: Source->Pong

Hi ha 5 carpetes:

DQN_Manager -> Codi principal amb l'algorisme DQN / Main code with DQN algorithms
          

Enviroment -> Codi que fa funcionar l'entorn i el cordina amb DQN / Code that runs the environment and coordinates it with the DQN

NeuralNetwork -> Xarxa neuronal / Neural Network + Backprop + Gradient Descent.

ReplayBuffer -> Codi de la memòria intermèdia / Replay Buffer

DataPiece -> Estructura de dades per guardar (estat acutal, acció, recompensa, estat següent, Done) / Data structure to save data as (actual state, action, reward, next stat, Done (boolean) )
